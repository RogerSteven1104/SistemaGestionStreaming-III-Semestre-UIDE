# 🎬 Sistema de Gestión de Streaming

## Descripción

Este proyecto corresponde al desarrollo de un **Sistema de Gestión de Streaming**, realizado como parte de la asignatura **Programación orienta a objetos** de la Universidad UIDE.

El objetivo principal del sistema es aplicar los conocimientos adquiridos durante las primeras unidades de la materia mediante el desarrollo de una aplicación en **Go (Golang)**, utilizando el paradigma de **programación funcional**.

El sistema permitirá administrar la información relacionada con usuarios, contenido audiovisual, categorías, planes de suscripción e historial de reproducciones, siguiendo una estructura organizada y escalable que facilite futuras mejoras.

---

## Objetivos

- Desarrollar un sistema utilizando programación funcional.
- Aplicar funciones, estructuras de datos y paquetes propios de Go.
- Diseñar una arquitectura organizada mediante un diagrama de clases UML.
- Implementar buenas prácticas de desarrollo utilizando Git y GitHub.
- Documentar cada etapa del proyecto.

---
